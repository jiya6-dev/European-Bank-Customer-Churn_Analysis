# 🏦 European Bank Customer Churn Analysis Dashboard

## 📌 Project Overview

This project analyzes customer churn patterns for a European bank using data analytics, customer segmentation, and machine learning techniques. The objective is to identify high-risk customer segments, understand churn drivers, estimate revenue risk, and support customer retention strategies.

The project includes an interactive Streamlit dashboard for business users and decision-makers.

---

## 🎯 Objectives

* Analyze customer churn behavior
* Identify high-risk customer segments
* Compare churn across demographics and financial profiles
* Quantify revenue risk due to customer attrition
* Discover key factors driving churn
* Build an interactive dashboard for business insights

## 📌 Key Business Insights

* Customer churn varies significantly across geographic regions.
* Older customer segments show higher churn risk.
* High-balance customers contribute most to revenue risk.
* Customer activity level strongly impacts churn behavior.
* Balance and age are among the most influential churn drivers.
